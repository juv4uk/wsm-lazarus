# wsm-lazarus — нативна система SENS на Free Pascal

Ціль цього репозиторію — **повноцінна система реалізації мови SENS, подібна за архітектурою до SBCL**: компілятор, runtime/GC, інтерактивний REPL, завантажувач бібліотек Core4, нативний backend, діагностика та образи системи.

Це **не реалізація Common Lisp**: усі мовні закони, доменні координати та канонічний формат джерел належать [juv4uk/sens](https://github.com/juv4uk/sens). Lazarus є реалізацією механізму, а не окремим джерелом семантики.

## Реальний стан

| Частина | Стан |
|---|---|
| FPC headless-збірка та CI | є |
| Точні доменні ключі / D1–D3 witness | є |
| Структурний компілятор `sensc --compile-ir` | є, формує тільки приватний SIR1 |
| Reader канонічного `.sens` | ще не реалізований |
| Доменне зв'язування та lowering | ще не реалізовані |
| Runtime, GC і виконання Core4 | ще не реалізовані |
| Повноцінний REPL, native codegen, образ системи | ще не реалізовані |

Докладні етапи, обмеження та критерії прийняття — [docs/native-system-roadmap.uk.md](docs/native-system-roadmap.uk.md).

## Поточний вхід компілятора

```bash
./scripts/sync-authority.sh
./scripts/test.sh
./build/m0.2/bin/sensc --compile-ir external/sens/lib/core4.lisp /tmp/core4.sir
```

`.sir` — внутрішній структурний формат, **не** скомпільована програма і **не** канонічний `.sens`. Команда є стартовою цеглиною для майбутнього front-end.

## Принцип

**SENS — семантичний авторитет; Free Pascal/Lazarus — нативна система реалізації.** SID8 не використовується як чинна система ідентичностей.

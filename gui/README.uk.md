# Двійковий інспектор SENS на Lazarus/LCL (M2.0)

Це справжня настільна програма Lazarus/LCL, а не HTML-імітація. Є кнопка вибору фізичного .sens, таблиця координат та рядок діагностики українською.

Дані надходять із вже злитого нативного механізму: wsm.t5m → wsm.d2source → wsm.binarybind; українська проєкція читається з pinned external/sens/lib/domains/d*.lisp. Назва функції не визначає значення. D1 0 і D3 000 — різні координати.

## Збірка та запуск

Після синхронізації pinned SENS та встановлення Lazarus/LCL GTK2:

    mkdir -p build/lcl/bin build/lcl/units
    lazbuild --ws=gtk2 gui/sens-inspector.lpi
    ./build/lcl/bin/sens-inspector

Програму запускати з кореня репозиторію, де є pinned external/sens; файл .sens можна вказати як один аргумент або вибрати через кнопку.

## Фізична перевірка

    bash scripts/test-lcl-inspector.sh

Збирає програму реальним lazbuild, запускає вікно під xvfb-run і перевіряє реальну TStringGrid: D3:111, D1:1, D3:000, українські колонки, відхилення пошкодженого T5M та відсутнього файлу без застарілих клітинок. Вхід обмежено 4 MiB фізичного T5M; UI відображає не більше 16384 слів.

Це лише GUI для точного фізичного зв'язування, не runtime-інспектор M2 за всіма критеріями #13, не REPL, не Core4 execution, не виконуваний compiler, не IDE, не семантичний oracle. #12 і повний #13 залишаються відкритими. Headless src/ не залежить від LCL.

## M2.1 — візуальне дерево фізичного D2

Ліва панель — справжній Lazarus/LCL TTreeView. Праворуч збережено плоску таблицю TStringGrid. Дерево будується виключно через вже злитий headless модуль wsm.binarytree.ReadBinaryTree із pinned фізичного T5M, структурного D2 і перевірених exact-domain координат. Виділення вузла показує верхню форму, глибину, фізичне слово, 0-based напіввідкриті трит- і байт-інтервали. Для похідної крапкової пари чітко зазначено відсутність власного фізичного слова, без вигаданого byte span.

Перевірка під Xvfb доповнена тестами реальних TTreeView-вузлів: список із D3:111 / D1:1 / D3:000; вкладена крапкова пара; вибір фізичного листка й похідного вузла; пошкоджений T5M, незакритий D2 і неіснуючий файл; очищення обох панелей після помилки. Незалежних мовних правил, нових означень Core4 або evaluator у GUI немає.

Відображення обмежене 16384 вузлами, і деревоподібна проєкція не є семантичним допуском чи виконанням програми. Повний M2 над runtime все ще залежить від задачі #12.

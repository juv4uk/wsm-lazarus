# Нативний візуальний огляд двійкового SENS

Це **Lazarus/LCL**-застосунок, не лише Free Pascal CLI. Він відкриває фізичний `.sens`, показує точні біти, домен/ширину, напіввідкриті інтервали тритів і байтів та необов'язкову проєкцію `ук` з pinned `external/sens`.

## Збирання з кореня репозиторію

```bash
./scripts/sync-authority.sh
mkdir -p build/lazarus/units
lazbuild -B gui/sensinspector.lpi
./build/lazarus/sensinspector
```

Потрібні Lazarus/LCL та GTK2. Вікно має кнопку **«Відкрити .sens…»**, таблицю фізичних слів і пояснення, що виконання/викличність не перевірено.

`./build/lazarus/sensinspector --самоперевірка` під Xvfb перевіряє створення вікна, сітку та незмінність D1/D3 бітів. `gui/test-inspectorview.pas` перевіряє модель без LCL, включно з негативними прикладами.

**Обмеження:** інспектор допускає максимум 4096 видимих слів з шириною 1–9; це межа інтерфейсу, а не закон мови. Немає виконання Core4, семантичного REPL, native-codegen або другого реєстру законів. GUI не змінює `src/` і не вбудовує LCL у headless runtime. Старі історичні значення, SID8 і Core1 не є основою.

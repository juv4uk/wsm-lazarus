# SENS — перший Lazarus IDE-пакунок (задача #712)

Це **інтеграція IDE**, а не друга реалізація SENS і не загальний компілятор.
Канон — фізичні двійкові `.sens`/T5M pinned `external/sens` Contract 12.0;
`.lisp` — українська `укр` проєкція. Числа — D12+, текст — D7 з
шістьма ратифікованими поверхнями `ук`, `укр`, `san`, `en`, `LISP`, `sym`.

## Встановлення
1. У Lazarus: **Package → Open Package File (.lpk)** → `ide/sens_ide_map.lpk`.
2. **Compile**, потім **Use → Install** (перезбирання IDE може бути потрібне).
3. Після встановлення: **Tools → SENS: мапа проєкту**.
4. Оберіть корінь локального `wsm-lazarus` або задайте `SENS_REPO_ROOT`
   до старту IDE.
5. Двічі натисніть потрібний файл або «Відкрити вибране в Lazarus».
   Існуючі `.lpi` відкриваються через штатний `DoOpenProjectFile`,
   а джерела — через `DoOpenEditorFile`.

Карта **відображає лише наявність файлу**, а не заявляє готовність
повного Core1, Core4, GC або компілятора. Вона відкриває вже наявний
`gui/sens-inspector.lpi` і `gui/sens-wide-compiler.lpi`; їхню
семантику не переносить. Ніяких shell-команд та виконання неперевіреного
ELF із IDE-пакунка немає. Фізичні `.sens` можна переглядати як файли,
але це **не** означає їхнього виконання.

## Збірка та перевірка
```sh
./scripts/sync-authority.sh
./scripts/test-sens-ide-map.sh
```
Тест виконує `lazbuild --ws=gtk2 -B` для **design-time IDEIntf**
пакунка та окремий Xvfb/LCL selftest тієї самої форми. Він перевіряє
два штатні навігаційні запити та відмови для хибного каталогу й індексів.
Це **не автоматизований доказ інсталяції/кліку всередині повної Lazarus
IDE**: цю частину треба перевірити окремо на справжньому встановленому IDE.

Профільні збірки Free Pascal, компіляторні ELF64 тести й самостійні
LCL-інструменти залишаються незалежними.

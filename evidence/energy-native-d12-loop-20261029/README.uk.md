# Повторюваний D24 native-loop benchmark

## Результат цього запуску

На Intel Core i5-6400, CPU affinity 2, governor `powersave`, turbo увімкнений, виконано два прогони по 30 випадково переставлених блоків. Кожна вибірка — 50 окремих запусків одного ELF; кожен активний запуск обчислює суму від 1 до 8 388 361. У кожному прогоні — 1 500 запусків на варіант. Вихідний код завершення `173` перевірений для всіх чотирьох виконуваних файлів.

| Виконуваний файл | Прогін 1: час / package RAPL | Прогін 2: час / package RAPL |
|---|---:|---:|
| SENS native ELF | 0,295 с (0,269–0,336) / 9,04 Дж (6,64–10,66) | 0,270 с (0,263–0,293) / 5,77 Дж (5,33–7,06) |
| C / GCC `-O2` | 0,397 с (0,367–0,436) / 12,11 Дж (8,89–13,31) | 0,365 с (0,357–0,394) / 7,64 Дж (6,90–10,45) |
| Rust `opt-level=2` | 0,184 с (0,163–0,228) / 5,86 Дж (4,30–7,66) | 0,162 с (0,153–0,177) / 3,81 Дж (3,26–5,03) |
| Free Pascal `-O2` | 0,308 с (0,288–0,339) / 9,52 Дж (7,24–10,63) | 0,289 с (0,279–0,300) / 6,29 Дж (5,68–8,53) |
| Idle-контроль: 50 запусків `/usr/bin/true` | 0,173 с (0,145–0,205) / 5,49 Дж (3,76–6,66) | 0,146 с (0,139–0,182) / 3,49 Дж (2,94–5,56) |

Числа в дужках — p10–p90 між 30 блоками. У другому прогоні вимірювач уже збережений у цьому каталозі й повністю перевірений; джерела workload і ELF ті самі. Загальне падіння RAPL в активних та idle-вибірках показує сильний вплив стану системи. Сирі дані обох прогонів збережені окремо; їх не об’єднано в один показник.

Це не рейтинг мов. GCC згортає суму в оптимізований цикл, Rust — у формулу з множенням, а SENS ELF та FPC виконують цикл. Отже, це порівняння цих бінарних файлів і їхніх компіляторних перетворень. Час включає старт процесу, завантаження ELF та (крім SENS) розбір десяткового аргументу.

Енергію за мовами визначити не вдалося. RAPL вимірює всю спільну апаратну зону, з фоновим навантаженням. Парна idle-діагностика після масштабування за тривалістю має інтервали, що охоплюють нуль; ці дані не дають пер-процесного споживання. Package/core/DRAM не додаються між собою.

SENS-бік тут — вузький генератор машинного циклу `BuildD12SumLoopELF` з фізичного D24 T5M, а не загальний source-to-native компілятор SENS. Це вимір поточної вузької нативної траси, не готовий бенчмарк повної мови чи REPL.

```bash
bash evidence/energy-native-d12-loop-20261029/build.sh
```

Перевірити відповіді без RAPL:

```bash
python3 -B evidence/energy-native-d12-loop-20261029/measure.py --check-only
```

Зняти новий апаратний звіт (потрібні доступні Intel RAPL зони; вихідний файл має бути новим):

```bash
sudo -n env SUDO_USER="$USER" python3 -B evidence/energy-native-d12-loop-20261029/measure.py \
  --output "$PWD/evidence/energy-native-d12-loop-20261029/new-run.json"
```

# Огляд синтаксичних голів фізичного SENS

Використання:

```sh
sensholovy --голови програма.sens external/sens
```

Команда читає **фізичний двійковий** файл `.sens` через чинний T5M/D2 reader, формує фізичне дерево `wsm.binarytree` та індекс перших дітей списків `wsm.binaryheads`. Виводить індекси списку й верхньої форми, точні домен і біти атомної голови, її фізичний номер слова, напіввідкриті інтервали тритів/байтів. Порожні списки, звичайні двійкові й структурні голови відокремлені. Крапкові пари не видаються за окремі D2-списки.

**Українська `.lisp`** — звичайна людиночитана проєкція, наприклад `(сполучити так)`. Вона **не** є фізичним T5M і тому не читається цією командою. Для структурної перевірки такого джерела існує окремий `sensbind --analyze файл.lisp external/sens`. Тотожність у SENS первинно визначають точна ширина, двійкові біти, домен та ратифікований закон; назви `ук` і **повна `укр`** — тільки відображення з pinned таблиць після встановлення точної двійкової координати. Команда зберігає колишнє поле `ук` для сумісності та додає `укр` для звичайної української `.lisp`-проєкції. Наприклад, точна D4:0101 має `ук=порожнє?`, але `укр=порожній?`; жоден текст не є автоматичним допуском до виклику.

Це тільки **синтаксичний** огляд. Перша дитина списку може бути даними, а не дозволеним викликом. Команда не виконує SENS, не є REPL, не здійснює загального `.sens`↔`.lisp` round-trip і не підтверджує виконання Core4.

**Доказ:** `scripts/test-sensholovy.sh` фізично компілює `sensholovy` та `senst5m` реальним FPC, пакує контрольні двійкові слова, перевіряє вкладені форми, точні координати й детермінізм, розділення D1:0 та D3:000, помилки T5M/D2, відсутній pin, українську `.lisp` як недопустимий бінарний ввід і порожній stdout при відмові. Окремий GitHub Actions — `.github/workflows/sensholovy.yml`. Ні Lisp-бібліотеки, ні закони, ні загальний FPC CI не змінено.

**Регресія G2.15:** повна колонка `укр` береться тільки з наявного `wsm.ukroundtrip.LoadPinnedLongProjection`, а не з нового словника чи з короткої `ук`. Тест додатково використовує реальний `examples/migrated/smoke-cond.sens` з exact pinned gitlink та відхиляє змінений pinned файл без колонки `укр`, не публікуючи часткового stdout. Позитивні фізичні й негативні D2/T5M тести збережені. Числову D12+ драбину він не тлумачить: вузький reader залишається явно обмеженим і не виводить семантику з ширини.

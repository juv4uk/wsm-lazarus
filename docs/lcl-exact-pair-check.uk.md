# Явний побайтовий доказ української пари у Lazarus

## Що змінилося

Наявне вікно `gui/sens-paired-witness.lpr` вже відкриває **два незалежні свідки**
з кореневого `juv4uk/sens`: звичайну повну українську `.lisp`-проєкцію
та канонічний пакований `.sens` (фізичний T5M). Кнопка
**«Перевірити точну відповідність»** тепер може довести ще одну властивість:
**для вже підтриманого оборотного піднабору** `укр` → фізичні T5M байти
точно збігаються з відкритим `.sens`. Це не автоматична дія при завантаженні.

Вхідний текст, фізичні байти, точні біти та графічні інтервали **не
змінюються** після натискання. Результат окремо показує один із трьох
спостережуваних станів: «не перевірено», «перевірено байт-у-байт» або
«не доведено». Якщо байти різні, останній стан прямо це вказує.
Помилка несумісної форми **не означає помилку мови SENS**.

## Звідки походить істина

Шлях із `.lisp` у канонічну фізику **не реалізується вдруге в GUI**.
Він делегує вже злитим `wsm.ukroundtrip.LoadPinnedLongProjection`,
`UkrainianToPhysical`, `PhysicalToUkrainian` із pinned таблицями
`external/sens/lib/domains/d1.lisp` … `d9.lisp`. Повні поля
`(укр ...)` — людська проєкція. Наприклад:

```lisp
(сполучити ні так)
```

Це окремий текстовий файл. Машинні біти — лише у `.sens`. Окремий
`senst5m --пакувати-слова` фізично породжує тестовий файл із
`10 111 0 1 01`, а GUI перевіряє вже **готові** файли, не підміняє
вміст чи зворотно не записує код.

Нормативне джерело — pinned
`external/sens/contracts/language-contract-12.lisp` та
`contracts/numeric-domains-ratification.lisp`.
Числова доменна драбина починається з **D12** та продовжується
**D24, D48, D96, D192** за власницьким рішенням; **D1 не є числом,
а будь-яка фізична ширина 13 біт не робить D13 ратифікованим
числовим доменом**. Поточний вузький `ukroundtrip` не пакує D12+
через `wsm.binarybind`. У вікні реальні root
`tests/semantic/d5-d12-numberp-law.{lisp,sens}` та
`lib/axioms-d1-principle-five.{lisp,sens}`
залишаються доступними як **самостійні свідки**: після явної
перевірки чесно показується «не доведено», а широкі слова та їхні
тритові/байтові адреси залишаються на екрані.

## П'ять інженерних принципів

Їх прочитано з pinned `docs/language-core-axioms.md`.
Це **принципи проєкту**, а не нові ратифіковані закони або семантичний
oracle:

1. **Можливості понад обмеження:** явна перевірка додає нову можливість
   для однозначних пар, замість примусової відмови від усього огляду.
2. **Lisp у повному розумінні:** звичайна українська проєкція зберігає
   списки й атоми, а не імітує англійський function dispatch.
3. **Машина міркування:** свідки, повна provenance і виразна причина
   «не доведено» важливіші за неперевірене припущення.
4. **Універсальність:** правильність фізичних байтів відокремлена
   від Lazarus Canvas; той самий FPC `ukroundtrip` працює без GUI.
5. **Сучасні технології символічного ШІ:** справжній Lazarus 3.0
   + GTK2/Xvfb GitHub CI випробовує реальні кореневі свідки й
   позитивні/негативні випадки з точними входами.

## Як відтворити

```sh
./scripts/sync-authority.sh
bash ./scripts/test-lcl-paired-witness.sh
```

Скрипт будує справжній Lazarus/LCL з `TButton`, `TMemo`,
`TStringGrid`, `TPaintBox.Canvas`, запускає вікно під Xvfb,
перевіряє успіх для точної `укр`-пари, відмову для
непов'язаної пари і справжніх pinned D12+ свідків, а також повне
очищення видимого стану після зіпсованого UTF-8/T5M.

**Це не виконання Core4, не інтерактивний REPL, не загальна числова
арифметика, не закон D12+ і не семантичний паритет двох програм.**

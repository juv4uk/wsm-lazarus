# Атомарний пакет різновкладених фізичних D5-програм

**Стан:** G6.150, інтеграційний зріз компілятора. Не універсальний
компілятор SENS, не нові семантичні закони й не копія Core1/Core4.

## Вхід і вихід

Шістнадцять **самостійних** канонічних фізичних `.sens` програм:
вісім лівовкладених D5:01010/01011 із глибиною 2, 3, 4, 5, 8,
16, 50, 100 та вісім правовкладених із глибиною 2, 3, 4, 5, 6,
7, 8, 16. Кожна має рівно один D2-корінь, exact pinned D5 W5
голови, signed D12 W12 атоми. Значення і ширини всіх проміжних
результатів допускаються чинними числовими механізмами; вихід за D12
відхиляється, а не звужується мовчки.

Джерело законів — **винятково** `external/sens` gitlink
`1f1bf676eeac605e065035d9dd2adaae807f1788` (Contract 12.0).
Реальне виконання програм спирається на чинні `BuildVerifiedWideELF`,
`BuildIRArithChainELF`, `BuildIRArithPravyELF`. Не додаємо
жодної альтернативної таблиці імен/opcode чи нового backend.
`.lisp` — українська повна проєкція `укр`, **не** канонічний вхід.
D7 підтримує шість проєкцій: `ук`, `укр`, `san`, `en`, `LISP`,
`sym`; числа — D12+.

Вже існуючий `senswideatompaketelf` готує всі 16 образів ELF64 PIE
до файлової публікації та створює новий каталог за допомогою
`mkdtemp` і `renameat2(RENAME_NOREPLACE)`. Це host Linux
механіка, не SENS закон. На відхиленому шістнадцятому файлі
не з'являється жоден частково опублікований каталог; наявні цілі
й символічні посилання не перезаписуються.

## Самодостатній тест

```bash
bash scripts/sync-authority.sh
bash scripts/test-wide-atom-nested.sh
```

За встановленого незалежного pinned SENS CLI:

```bash
SENS_ORACLE_BIN=./sens-oracle/target/debug/sens \
REQUIRE_SENS_ORACLE=1 \
bash scripts/test-wide-atom-nested.sh
```

Доказ: checked FPC 3.2.2 з `-B -Cr -Co -Ci -gl -gh`, дві наявні
програми-генератори з 71 і 36 позитивними свідками, рівно 16 вибраних
фізичних джерел, 16 ELF64 PIE, побайтове порівняння кожного з
одиночним компілятором, 16 реальних машинних відповідей як exact
фізичні 3 байти D12, 8 негативів, повторний пакет після відмов
та 16 незалежних SENS REPL результатів у режимі oracle.
Універсальна форма дерева з двома незалежно вкладеними піддеревами,
GC, Core1 lexical closure, повний REPL та Lazarus IDE цим тестом
**не доведені**.

## Обмеження вимірювань

Тест НЕ вимірює енергію, затримку чи продуктивність. Для фізичної
енергії необхідний окремий апаратний RAPL-лічильник і узгоджені
міжмовні навантаження. Зелений CI не означає доведеної
енергоефективності або завершення системи рівня SBCL.

# Звичайна українська проєкція `.lisp` фізичного `.sens`

## Принцип

**Канонічне джерело мови SENS — двійковий `.sens`**, точні доменні
координати та ратифіковані закони з pinned `external/sens` (Contract 12).
Файл `.lisp` — тільки **людиночитана українська проєкція**: він містить
звичайні українські слова, а не числа доменів, двійкові рядки чи
англійські імена функцій.

Наприклад, фізичні D2 `10`, D3 `111`, D1 `0`, D1 `1`, D2 `01`
відповідають звичайному українському файлу:

```lisp
(сполучити ні так)
```

Назви `сполучити`, `ні`, `так` **не задані в Pascal**: вони читаються
із затверджених `(ук ...)` полів pinned таблиць доменів. Вони лише
відображають точні координати, не визначають їхню семантику. Ні читання
`.lisp`, ні його пакування не виконує програму.

## Команди

Після `./scripts/sync-authority.sh` та компіляції інструмента
`src/sensukrlisp.lpr` Free Pascal:

```sh
sensukrlisp --вивести-ук програма.sens програма.lisp
sensukrlisp --пакувати-ук програма.lisp відновлена.sens
cmp програма.sens відновлена.sens
```

Перша команда перевіряє **повний** T5M і структуру D2, унікальну
`ук`-поверхню та виконує зворотне пакування **до** запису `.lisp`.
Друга використовує чинний український UTF-8 reader, pinned domain binder
і **наявний** T5M encoder. Звичайні пробіли, переводи рядків та коментарі
`;` допускаються на вході; результат нормалізується до одного пробілу
між елементами і одного LF після кожної форми. Два корені тексту — два
рядки. Новий файл публікується лише після всіх перевірок, без
перезапису вже наявного імені (тимчасовий файл та POSIX hard-link).

## Строгі обмеження — чесна межа оборотності

**Це не повний `.sens ↔ .lisp` конвертер.** Операція є оборотною
виключно для фізичних програм із простих proper-list D2 дужок
`10`/`01` та атомів, що мають унікальну звичайну
українську `ук`-назву в pinned таблицях D1, D3–D9. Відкидаються:

- фізичний D3:000, тому що його відсутнє `ук`-ім'я `()`
  **зовні не відрізняється** від порожнього proper D2-списку `10 01`;
- **явний D2:00**: текстові пробіли не дають можливості відновити,
  чи це фізичний структурний токен, чи лише оформлення;
- **D2:11** та похідні крапкові пари, для яких звичайний читач
  `wsm.source` ще не має ратифікованого фізичного зворотного
  тлумачення;
- координати з порожньою, повторною між доменами або синтаксично
  неатомарною поверхнею, невідомі назви, рядки, пошкоджений UTF-8,
  неправильні/надмірні T5M байти, понад 32768 фізичних слів,
  понад 1 МіБ тексту та D10+, які ще не підтримуються physical D2.

Ці відмови **навмисні**. Не можна замінити D3:000 на D2-порожній
список, видалити D2:00 або вгадати домен за назвою без втрати
канонічної двійкової тотожності. Для таких програм продовжуємо
застосовувати фізичні інструменти `senst5m`, `sensbinary` і `sensvykon`.

**Тестова вимога:** `scripts/test-ukroundtrip.sh` збирає нативний
Pascal із `-Cr -Co -Ci`, перевіряє пари `.sens → .lisp → .sens`
побайтово, відмови без часткового stdout/файлу та реальну українську
UTF-8 проєкцію. Це **механічне свідчення**, не SENS REPL-оракул,
не Core4 loader і не виконуваний компілятор.

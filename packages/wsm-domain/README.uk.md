# wsm-domain

Пакет FPC для наявного unit `wsm.domain`. Він залежить від пакета
`wsm-source` і використовує його reader для повної структурної перевірки
таблиці перед публікацією результату.

## Публічний API

`TDomainKey` зберігає `Width: Byte` та `Bits: Word` окремо, тому
`1`, `01` і `001` не зливаються в одну адресу. `ExactKey` приймає
лише двійковий рядок шириною 1..10; `KeyBits` відтворює його точну ширину.
`LoadDomainTable` будує таблицю атомарно: при помилці `Rows` залишається
порожнім, а викликачу передається лише повністю перевірений результат.
Помилки мають тип `EDomainError`.

Це механіка точних координат і читання pinned-таблиці, а не локальне
визначення значення координат, evaluator або dispatch. Пакет не активує
історичні SID8-модулі, не залежить від LCL і не змінює контракт SENS.

Пакетна збірка й smoke-test описані в [загальній інструкції](../README.uk.md).

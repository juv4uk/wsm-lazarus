# wsm-source

Пакет FPC для наявного unit `wsm.source`. Це структурний UTF-8 reader
української текстової проєкції: він створює AST, зберігає точні байтові
інтервали та діагностує некоректний UTF-8/структуру.

## Публічний API

`ReadUkrainianSource(const Source: RawByteString): TSourceDocument`
повертає дерево `TSourceDocument`. Власником документа стає викликач:
після читання його потрібно звільнити через `Free`. Документ рекурсивно
володіє кореневими `TSourceNode`, а вузли — своїми дочірніми вузлами.
Помилки читання мають тип `ESourceError` та містять `ByteOffset`,
`Line` і `ByteColumn`.

Unit використовує лише RTL (`SysUtils`, `Classes`); залежності від LCL
немає. Він не декодує фізичний `.sens`, не зв'язує домени, не виконує
програм і не є семантичним оракулом SENS.

Пакетна збірка й smoke-test описані в [загальній інструкції](../README.uk.md).
